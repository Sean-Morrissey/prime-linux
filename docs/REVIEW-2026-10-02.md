## Making the stable channel real (owner, once)

The machinery is written and tested (`tests/check-release-signing.sh`); it only needs
the first signed release. On the computer that holds the release key's private half:

```
git checkout main && git pull
git tag -s v2026.10.0 -m 'Prime Linux 2026.10.0'
git branch -f stable v2026.10.0
git push origin stable v2026.10.0
```

Then change the default in `boot.sh` (`PRIME_BRANCH:-main` → `stable`) and the curl
line in `docs/USER-GUIDE.md` to `…/stable/boot.sh`. From then on every friend's
computer installs only releases that key signed; `main` stays the test channel.
